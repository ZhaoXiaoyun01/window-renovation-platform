# 外窗安装防渗漏核对

来源：参考 [zx029w/zhuangxiu-skills](https://github.com/zx029w/zhuangxiu-skills) 的安装验收问题排查方式，由本项目重新编写。具体广东建议以本地标准库中已核实的 2026 年指导性技术指南为准。

1. 区分厂内样角构造与墙体现场安装，先取得框墙节点、固定方式、室外侧防水、窗台坡向与排水孔资料。
2. 重点核对四角密封、框墙缝隙有效密封、固定片方向、滴水构造和排水孔畅通；分别记录图纸证据与现场照片证据。
3. 若只提供产品样角，现场安装结论保持未确定，列出需要补拍的部位和验收方式。
4. 广东 2026 指南是指导性文件；运营期整治后的持续淋水 24 小时不能写成所有新装窗统一强制门槛。
