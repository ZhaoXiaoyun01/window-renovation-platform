# 门窗样角与配置核对

来源：参考 [zx029w/zhuangxiu-skills 的门窗封窗避坑指南](https://github.com/zx029w/zhuangxiu-skills/tree/main/menchuang-fengchuang-bikeng-zhinan) 的按主题定位、先指出风险再给补证办法的流程。本文件为本项目重新编写；不复制其会员文章，也不把西安经验视为广东规范。

1. 先辨认文件类型、内外侧方向、框扇/玻璃/胶条/排水腔，记录可见文字或部位。未标尺寸时仍可判断可见的接触与排水路径；不能编造尺寸或性能等级。
2. 样角逐项看密封连续与四角、下框排水向室外、玻璃槽排水、隔热带连续性、玻璃垫块着力、拼角、外开副框接缝、窗纱一体内侧扇腔、螺钉穿越隔热带和墙体安装界面。
3. 先写画面中看到什么，再写“据经验，可能带来什么风险”，最后写商家应补哪张节点图、哪项同型号报告或哪种现场验收。可见风险是线索，不是已发生渗漏或工程不合格。
4. 三道密封是本用户选购目标，不是通用国标强制数量。型材波浪外形本身不能证明性能差。真实等温线、水密等级、承载力和材料真伪要靠计算、试验或可追溯资料。
5. 规范结论只引用标准库已核实且适用于项目的条文。视频画面或开源 Skill 只作为经验线索，不能冒充标准或博主逐字观点。
