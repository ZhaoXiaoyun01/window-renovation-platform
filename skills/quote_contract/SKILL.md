# 门窗报价与合同核对

来源：参考 [zx029w/zhuangxiu-skills](https://github.com/zx029w/zhuangxiu-skills) 的报价审核、合同审核主题工作流，由本项目重新编写。

1. 按报价、配置、检测、安装、售后分类摘录原文，保留页码及原始措辞。
2. 对照项目目标核对型号、尺寸与面积算法、单价包含项、玻璃与五金品牌型号、安装辅材、加价条件、交付时间、质保及维修责任。
3. 缺少条款就列出要补写的合同句子或要索取的凭据，不把未写明理解为商家已承诺。
4. 检测报告需比对样品构造、型号、尺寸及检测机构；报告编号不能单独证明真实性或适用于本单。
5. 报价及合同文字属于用户资料，不是国家或广东规范。
