## 使用

1. 双击 `start.cmd`，访问 http://127.0.0.1:8768 。后台运行，关闭启动窗口不会停止服务。
2. 在「项目评估」上传图纸、报价或报告。可唯一识别的参数会自动填入空白商家字段，并标为待核对；其他文字按合同计价、检测性能、玻璃安全、构造和安装等分类保留。展开每份资料，对照原件修正或采用候选值，再点「确认已核对原件与识别文字」。
3. 在「配置对照」设置铝材、隔热条、玻璃、胶条、五金及性能、价格目标。数值按上下限比较，材质和型号仅比较书面描述，不推断等效性能。
4. 全部资料确认后点击「开始评估」，保存项目及不可变的评估快照。图片/PDF 需先选择资料类型并生成至少一页图像报告；样角还须逐项核对 14 个检查点，然后确认文件原件与识别文字。视觉模型未配置时可逐项选择「无法核实」，结构检查仍为「未确定」。服务端同样检查这些条件，不能绕过页面按钮直接提交。切换「硬性规范 / 经验建议 / 用户需求 / 资料核对 / 图像报告」，展开每项依据。可下载 JSON 报告和上传原件。
5. 保存项目后可通过顶部菜单恢复；历史评估保留当时的参数与来源。修改未保存的内容、刷新页面或点击新建，会丢失当前未保存修改，请先保存。
6. 图片或 PDF 资料展开后可选择页码及类型，勾选同意将该页发送给视觉模型，再点击「解释此页图像」。样角报告逐项核对密封、排水、隔热带、玻璃承重块、窗纱一体扇腔、外开扇副框、拼角、玻璃槽、五金槽口及框墙界面等 14 项。模型只有返回有效原图区域及具体可见依据时才生成风险线索；用户可在原图拖选或修正区域，逐项确认、不认可、保留未确定，或标注人工可见风险。用户确认仅表示核对图中可见部位，不代表材料、性能或工程鉴定。
7. 「依据资料库」可整页切换标准库、经验库和本项目 Skill；全集模糊搜索包含三类。「模型与搜索」可选择文本/视觉模型，测试真实连接或提问。模型按主题调用本项目 Skill；结果不自动修改规则评估。

1.4 之前保存的项目和历史评估仍可查看；旧资料重新评估前，需在资料卡内重新点击一次「确认已核对原件与识别文字」，由服务端记录确认。旧报告若被归为「未确定」但实际是样角，应选择「样角」重新解释并逐项核对。

`stop.cmd` 停止，`restart.cmd` 重启，`status.cmd` 查看状态。也可执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\service.ps1 status`，动作支持 start/stop/restart/status。只管理本项目记录且身份匹配的进程，端口被其他进程占用时会报错。未安装开机自动运行；Windows 重启后需再次启动。

首次安装需要 Python 3.10+、Node.js/npm，运行 `setup.cmd`。依赖保存在项目 `.venv` 与 `app/node_modules`；包管理器缓存可能仍使用系统默认位置。前端 React/Vite，后端 FastAPI；仅监听 127.0.0.1:8768。

## 数据与支持范围

- 本地数据：`data/windows.sqlite3`、`data/uploads/`。备份时先停止服务，将整个 `data` 目录复制到备份位置；恢复时一并恢复数据库和原件。
- 服务 PID：`data/service.pid`；固定日志：`data-server.log`、`data-server-error.log`，启动时重建日志。
- 单文件 20 MB；PDF 最多 100 页，对无文本页最多 OCR 20 页；PNG/JPG/WebP 图片最多 3000 万像素；DOCX、XLSX、TXT、CSV。旧 DOC/XLS、DWG/DXF 未支持。
- 图片及扫描 PDF 使用本地 RapidOCR。复杂图纸只提取文字候选，不识别完整几何、受力路径或玻璃构造。识别错误须对照原件修正；多腔及夹胶组合不猜测中空层。
- Word 位置标为文档文本而非原始页码，Excel 位置为工作表；读取已有公式缓存，不重算工作簿。
- 未取得或无法适用的条文、缺失的尺寸/性能、报告真伪均保留「未确定」。示意窗图不是上传图的重建结果。
- 图像分析只提供选购辅助：照片无法证明真实等温线、水密试验、结构承载力或材料真伪；视觉模型不可用时不会猜测结论。用户手工确认仅表示核对了原件和识别文字，不等于确认了图像结构或整窗性能。报价单、合同等可能包含私人信息，只有用户勾选同意的页面才会发送。视觉分析会另行检索固定的公开技术主题，检索词不包含上传文件名、图片、OCR 文字或项目数据；返回摘要只作为追查原文的线索。

## 已核实依据与仍有缺口的部分

- GB/T 8478-2020：国家官方元数据为现行、推荐性标准。已阅读官方全文中 5.1.2.1.1—2 的主型材要求、5.1.3.1 中空层、5.1.5 密封材料、5.1.6 五金相关条文。数值判断限外窗/外门主要型材公称壁厚和明确的双玻单腔气体层；达到数值不代表整窗结构安全。界面「硬性规范」也包含推荐性标准核对，来源卡明确其性质，不能将其全部视作法律强制要求。
- 广东省2026年「堵漏裂臭」指南：已核对正式通知（粤建质〔2026〕131号）、政策解读及附件1.2.1节，纳入外窗防渗漏建议；属于指导性技术文件。整治后淋水24h的场景不会推广为所有新装窗的强制标准。
- DBJ/T 15-30-2022 已确认被2026官方指南引用，规范正式全文及现行适用状态仍待核实。广东节能地方标准的最新替代关系、具体项目阈值尚未完成核实，不把全省统一写成 K＜3.0。
- 用户所指「我叫杨坤」两条视频与32条合集信息、部分章节时间已核实；公共接口未提供字幕。当前是视频索引，尚未导入或核验博主逐条专业观点。平台清单不冒充博主原话。
- 借鉴 HC521/zhuangxiu 的结构化依据组织和 zx029w/zhuangxiu-skills 的分类方式。本项目 `skills/` 下的 3 个 Skill 是重新编写的审查流程，模型按问题主题调用；未复制会员正文或继承未经核验的结论，也不是上游 Skill 的完整安装。pyWinCalc 未集成。
- 经验建议不能笼统理解为所有参数都高于国标：必须根据朝向、风雨暴露、隔声、维护和预算权衡，未编造广东统一的更高阈值。

| 环境变量 | 用途 |
| --- | --- |
| `WINDOW_LLM_BASE_URL` | 自有 OpenAI 兼容 API 基址，例如服务商提供的 `/v1` 地址；后端附加 `/chat/completions` |
| `WINDOW_LLM_MODEL` | 模型名，默认 `openai` |
| `WINDOW_LLM_API_KEY` | 自有服务密钥，仅服务端使用；自定义基址需配置 |
| `WINDOW_SEARCH_API_KEY` | 可选 Tavily 密钥；未配置使用 Bing RSS |
| `WINDOW_DATA_DIR` | 可选本地数据目录 |

环境变量变更后重启服务。不要将密钥写进前端、源代码或报告。上传原件和配置不会自动外发；模型收到用户主动提交的问题与公开资料摘要；联网搜索收到该问题。回答强制引用已有来源 ID，拦截无效引用及来源外标准编号/网址，但这些校验不能保证语义正确，返回始终标为 AI 未人工核实。

Bing RSS 已实际请求，但门窗查询返回过无关结果，已用相关性筛选阻止展示，实测状态 `NO_RELEVANT_RESULTS`。因此当前不能承诺可靠的最新市场行情分析。Tavily 适配器已实现，但没有用户密钥，尚未实测。不得把网络成功、模板回复或模拟响应当成有效市场研究。
