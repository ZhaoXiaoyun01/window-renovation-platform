# 装修4.1：窗户批量操作、玻璃升级报价与柔金选中

日期：2026-11-05（Asia/Shanghai）。在4.0已有实现上增量更新，独立装修模块递增至4.1；原门窗业务/API仍1.5，方案格式1、分面修订11、缓存键保持。没有重新搭建模型或迁移正式数据库。

## 本次完成

1. 窗户统计表不再在窗名下显示两行小字。尺寸/报价状态移至表格上方默认折叠的「尺寸与报价依据」，窗户侧栏及Excel依据页继续保留，未核实状态未被删除或改作已核实。
2. 窗户侧栏增加「高亮全楼原同类型窗户」及「替换全楼原同类型窗户」。选中时记录原类型；尺寸、分格/开启方式、颜色、玻璃透光、扇数、基础价格及升级规格/单价一致的窗户归为同类型，名称和报价历史不参与归组。隐藏楼层也纳入匹配与替换，显示高亮时保持原显隐。
3. 未改动类型属性或报价记录时，替换按钮禁用。修改后将选中窗的窗框颜色、玻璃透光、扇数、基础价格、玻璃升级及报价记录应用给原同类型窗；选中后另被独立改动的目标不覆盖。保留每樘窗的独立名称、洞口尺寸/位置及原分格。整批操作作为一个编辑步骤，可撤销/重做；撤销及切换方案后重新建立选择基线。
4. 批量操作保留目标旧报价记录，追加来源窗记录，并生成目标专属记录ID/窗户ID及「沿用Wxx报价」来源说明。来源窗的已确认报价在目标窗降为未核对的商家报价，不能把一樘窗的人工确认直接当作另一樘窗已确认。历史报价、日期及原配置不被抹除；升级规格或单价改变后，旧报价自动标记待重核。
5. 新增可选玻璃升级，报价按窗户宽×高的总面积另计（未扣窗框，不声称是玻璃净面积）。选择规格时带入用户提供的初始单价，允许手动修改及零价；切回「无升级」不加价。旧方案缺少此字段时保持原总价。

| 玻璃升级规格 | 用户提供的初始单价（元/㎡） |
| --- | ---: |
| 5+(6-27)A+5离线LOWE | 28 |
| 6+(6-27)A+6离线LOWE | 55 |
| 8+(6-27)A+8离线LOWE | 203 |
| 10+(6-27)A+10离线LOWE | 350 |

这些初始价不是经验证的商家实时报价；空气层厚度仍为用户提供的范围，实际采购规格需核实。现有Low-E透光选项继续负责视觉模拟，升级报价不据此虚构玻璃物理性能。

6. 窗户统计表及Excel增加升级规格、升级单价、升级金额，支持原有表头下拉筛选、实时编辑及筛选快照导出。总价=窗户面积×（基础单价+升级单价）+开启扇数×每扇加价；金额按分四舍五入。主表15列，Excel报价记录16列，配置依据/交付说明保留。表格内部横向滚动，表头居中，不扩大弹窗或页面宽度。方案对比同步显示升级规格、前后升级单价及窗户总价差。
7. 先用实际模型生成A柔金、B雾蓝、C青灰三个预览，用户明确选择A后才将共享选中色从`#FFFF00`改为柔金`#D6B35A`。面/窗户/组件、同材质/同类型高亮与检查定位框共用此色；3px边框及点阵保持。柔和配色不代表经过医学护眼验证。页面蓝白主题、窗户实际颜色、模型几何及相机控制保持。
